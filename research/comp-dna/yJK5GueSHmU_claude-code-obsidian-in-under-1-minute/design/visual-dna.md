## Archetype
"Kinetic-text + 3D mockup-object explainer" — host-less, no face cam. Alternates between (a) floating 3D-rendered UI objects/cards with soft drop-shadows on a plain cream background, and (b) full-bleed editorial typographic statements on dark bg with particle/node animation. Occasional real screen-recording (terminal, code editor) inserted for credibility.

## Hook mechanic (first 3s)
Cold open on a relatable everyday object (a 3D notecard/notes stack) paired with the second-person setup line "If you take notes" — no logo, no face, no context card. Payoff line appears within 2s ("Claude became your best thinking partner") over a glowing starburst mind-map, so the promise is delivered before 3s. Curiosity is generated by object-recognition + incomplete sentence, not by shock or a question.

## Caption grammar
No burned-in bottom-third captions synced to VO. Instead: sparse, large, centered display text is *the* visual — one short phrase per shot (3-6 words), word-by-word or line-by-line reveal, italic used for the single emphasis word (Claude, custom, actually). Card/pill text is a separate register — small monospace/pixel caps inside 3D UI-mockup objects (e.g. "CLAUDE CODE", "/today"), styled like real app chrome, not like captions. Two distinct type systems: narrative statement type (serif/editorial) vs. UI-mockup type (mono/pixel, all-caps).

## Information density
Low-to-medium. Roughly one idea/beat per 2-4s. Steps are shown as isolated objects (one card, one command, one chip) rather than dense screen captures — density is manufactured through motion (multiple pills flying in) not through simultaneous text. Real screenshots (Obsidian plugin page, terminal, code editor) are shown briefly (1-2s) and are the densest frames, used only for authenticity flashes, not for teaching detail.

## Reusable asset components
- "3D floating object card" — soft-shadow, slightly rotated icon/app-mockup on plain bg (notecards, Obsidian logo, app window)
- "Vault/note-list mockup" — dark rounded card listing "New note N / MD FILE" rows with a bottom label bar (VAULT)
- "Named note pill" — small rounded chip with file icon + label (e.g. "Project Notes"), connectable via dotted line to other pills
- "Node/graph reveal" — particle points that animate from scattered lines into a converged shape (starburst or brain silhouette)
- "Terminal command card" — real (or mocked) dark terminal window showing a typed CLI command, red-highlighted key line
- "Slash-command app card" — teal/mono "CLAUDE CODE" branded card with a `/command` line and a result list below it (calendar/tasks/notes chips)
- "Editorial statement slide" — full-bleed dark bg, centered serif text, italic emphasis word, generous line spacing
- "Squiggly connector line" — hand-drawn-style line linking two floating chip cards to imply relationship/sequence

## Colors → content mapping notes
- Cream/off-white (#EAE7E0-ish) bg = "real world / narrative" beats (hooks, statements, object shots)
- Near-black (#0F1210-ish) bg = "concept/payoff" beats (mind-map, brain-web, big claim text) — reserved for the emotional high points
- Mint/teal green (#5FBFA0-ish) = the product's brand color, used for all Claude Code UI mockups (cards, pills) — consistent accent regardless of scene
- Dark green (#0F2E27-ish) = secondary/deeper UI surface (vault card, plugin screenshot bg)
- Red highlight text inside terminal = "the exact command to copy," a deliberate call-to-action color used only there

## Weaknesses / what NOT to copy
- No captions synced to spoken VO means audio-off viewers depend entirely on the sparse on-screen text — risky for retention if VO carries key info not shown as text
- Screen-recording inserts (terminal, code editor) are low-res/blurry and shown too briefly to actually teach the step — reads as "vibes of proof" rather than a followable tutorial
- Two unnamed/uncredited custom commands (`/today`, `/emerge`) are shown as magic outputs with zero visible setup — could feel like a black box / undeliverable promise to a skeptical viewer
- Pacing relies on ~1 cut/sec throughout with no variation — no beat of stillness to let the viewer read/absorb the densest proof frames (16-19s, 43-44s)
- Ending line "Claude connects the [dot] for you" is abstract/poetic rather than a concrete CTA (no next-step, no link, no explicit "try this")
