## Archetype
"Kinetic-text explainer + icon-mascot flow diagram" — no host, no face-cam. Pure motion-graphics: word-by-word VO-synced text beats intercut with a recurring teal robot-mascot / funnel / flowchart icon system, plus occasional real product-UI screenshots as proof.

## Hook mechanic (first 3s)
Opens on an abstract flow diagram (colored squares chained by dotted lines + a cursor icon) with zero text — pure shape/motion curiosity — then immediately anchors cost/value via "Less than your [Uber Eats] order," pairing a familiar cheap-purchase reference with an unfamiliar visual. No spoken product name yet; delays the reveal to build intrigue.

## Caption grammar
Not burned bottom-third subtitles. Text is the primary visual: large serif/sans slab, center-screen, 1-4 words per shot, changing every ~1s in sync with VO — essentially the whole video is kinetic typography with icon interludes rather than talking-head + caption overlay. Product-UI screenshots carry their own native in-app text (chat bubbles, chips) without extra overlay.

## Information density
Very high cut rate (~1 cut/sec) but LOW density per screen — almost always one idea/word/icon per frame. Density is achieved through rapid sequencing, not cluttered single frames. Occasional screenshot frames (chat UI, spreadsheet mock) carry denser real content as "proof" beats, contrasting with the sparse typographic beats around them.

## Reusable asset components
- **Word-build title card** — single word/short phrase, centered, serif or sans, on flat bg; used repeatedly to build a sentence across cuts.
- **Mascot icon (teal rounded robot/square-face)** — a consistent brand character reused across many beats as the "agent" stand-in; recolors/recontextualizes but shape stays fixed.
- **Funnel/gradient-label component** — a colored gradient triangle/funnel with a task-name label feeding down into the mascot icon; reused for each task type (market research, Reddit threads, competitive landscape) as a themeable "task→agent" unit.
- **Judge/verdict icon (wig mascot + red X / green check)** — represents pass/fail evaluation gate; binary icon swap communicates iteration without dialogue.
- **Chat/product-UI screenshot frame** — rounded-rect phone/browser mock with chat bubbles or input field, used as literal proof-of-product beats.
- **Assembly-line row** — multiple mascot icons connected by a dotted horizontal line with small labeled chips above each, representing a sequential multi-step pipeline.
- **Flowchart/tree diagram** — small icon nodes connected by right-angle lines, used at open and close to bookend the pipeline concept.
- **Stat/number closer card** — bold headline number ("Total $35 token spend") over a solid accent block, closing beat.

## Colors → content mapping notes
- Warm off-white/beige (#DEDAD1-ish) = default background for nearly every shot — keeps the whole video feeling like one continuous canvas despite fast cuts.
- Orange/coral (#EA5A2B-ish) = "cost/attention/negative-or-key" accent — used for the opening block, X/reject icon background, and the closing stat block.
- Teal/green (#3D8F7A-ish) = "agent/positive/product" accent — used for the mascot, checkmarks, funnel fills, and brand wordmark color.
- Purple/lavender = reserved specifically for chat-bubble/message UI mockups (distinct sub-palette signaling "this is a UI screenshot, not a graphic").
- Black/charcoal = text and line-art, plus a black chip/badge for "Sign up" buttons.

## Weaknesses / what NOT to copy
- No host or face at all — relies entirely on motion graphics + VO; would not work if the channel's DNA is host-led (e.g. claude-tricks' Sol pip).
- Single-word-per-screen pacing is EXTREMELY fast (near 1 cut/sec) — accessible only because there's a strong ambient VO carrying meaning; without matching VO pacing, captions alone would feel like a strobe.
- Brand-name reveal delayed via foreign-script katakana is a novelty gag specific to this brand's transliteration pun — not portable to other product names.
- Icon reuse (mascot, funnel, judge) requires a bespoke illustrated character set built in advance; not a quick per-episode reskin unless the mascot is treated as a fixed channel brand element.
- Several mid-video beats (t=22-27s chat bubble buildup) are fairly abstract/UI-heavy with sparse real content — retention risk if the audience isn't already primed on the product category.
- No visible on-screen source citation/URL — proof screenshots (Reddit, spreadsheet) are illustrative mockups, not verifiably real captures; copying this without real captures could undercut credibility for a channel that values proof-of-work honesty.
