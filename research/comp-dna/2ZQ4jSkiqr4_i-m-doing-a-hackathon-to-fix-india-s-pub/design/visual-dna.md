## Archetype
Talking-head monologue + insert cards (single static host shot outdoors, interrupted by full-bleed branded UI/reward/quote insert frames). No b-roll cutting within the host shot — it's one unbroken take carrying the whole 93s runtime, punctuated by ~6 short branded inserts.

## Hook mechanic (first 3s)
Mock-formal spoken opener ("Ladies and gentlemen...") over a static wide host shot in front of a recognizable govt-building backdrop. No visual trick, no zoom, no text card before the host starts talking — the hook is entirely verbal/tonal (absurdist formality) paired with word-by-word caption reveal that forces the eye to track and creates reading momentum immediately.

## Caption grammar
- One short phrase (2-5 words) per pill, roughly 1 new caption per second — near word-by-word karaoke-style reveal, not full sentences.
- Solid yellow rounded-rect pill, black bold uppercase text, black outline/shadow.
- Fixed position: centered, chest/waist height, never covers the face.
- Captions are the ONLY on-screen text during host segments — no lower-third name tag, no logo bug.

## Information density
Low-to-medium. Sentence fragments arrive fast (~1/sec) but each fragment is short and simple (5th-grade reading level). Visual density is low — static background, static host, single caption element on screen at any time. Insert cards (screenshots, reward cards, quote card) are the only moments of higher visual density, and each holds for only 1-3 frames (~1-3s).

## Reusable asset components
1. **Word-pill caption** — rounded yellow pill, black bold text, centered low-third; themeable fill/stroke.
2. **URL/brand title card** — logo mark + wordmark + URL on flat/light background, held 2-3s.
3. **Quote/tagline slab** — single line tagline on textured (notebook-paper-like) background, small logo corner mark.
4. **Reward/product card** — icon or product shot centered on soft gradient background, one line of bold caption text below (used for "Codex Pro For 1 Year", MacBook Pro insert).
5. **Screen-record proof insert** — raw phone/browser screenshot full-bleed, used to show the "before" (bad govt website) as evidence.
6. **End-card poster** — logo mark, tagline, "Registrations open" line, URL, presenter credit — static held frame acting as a CTA billboard.

## Colors → content mapping notes
- Yellow (#F5D400-ish) = caption/attention color throughout, consistent regardless of topic — the one true "brand color" of this format.
- Background is naturally desaturated blue-grey sky/park (uncontrolled, not a designed palette) — not really themeable as "brand" color, just whatever real location was shot.
- Insert cards use a soft pastel gradient (blue→lavender→peach) distinct from the outdoor host shot, signaling "this is a graphic, not the live feed."
- Tricolor (saffron/white/green swoosh) appears only on brand/logo cards — reserved specifically for the campaign identity, not used elsewhere.

## Weaknesses / what NOT to copy
- Zero visual variety in the host shot for ~90s — same static angle, same framing, same background the entire video; relies entirely on verbal content + caption pacing to sustain interest, which is a high-risk bet without strong delivery/charisma.
- No captions-off readability fallback issue, but caption cadence is so fast/fragmented that muted-scroll viewers may lose the sentence thread between insert-card cutaways.
- Reward/prize cards (Codex Pro, MacBook) are stock-looking gradient cards with no strong visual identity — feel like generic app-store promo art, weakest asset in the set.
- No explicit numbered/step structure despite being a "how to apply" CTA video — relies on prose narration only, missing an obvious step-card opportunity (e.g. "1. Build a demo 2. Submit link 3. Win").
- End card is held identically for 3+ seconds with no added info — wasted beat that could carry a stronger final CTA graphic (e.g. QR code) instead of a repeat.
