# Visual DNA — rkbacGroezI ("99% don't know this ChatGPT feature!")

## Archetype
Selfie-vlog walkthrough + laptop screen-record demo ("face-cam + screen-record proof")

## Hook mechanic (first 3s)
Direct-to-camera selfie, walking, mid-motion energy. Claim-first line ("coolest thing you can do with AI today") with no delay, no title card, no logo bumper. Face fills frame, handheld wobble signals authenticity/realness over polish.

## Caption grammar
Word-synced burned captions, 2-3 words visible at a time, white bold text on solid pink/magenta rounded pill, lower-third placement, updates almost every ~1s (near word-level pacing). No punctuation, all lowercase-feel casual phrasing matching speech. Caption pill color is the ONE consistent accent across the whole video regardless of background.

## Information density
Medium-high: constant narration overlaid on screen-record with no dead air; UI screenshots are shown just long enough to read the gist, not long enough to actually read line by line (viewer trusts narration, doesn't need to parse text). Escalating proof structure: prompt → output image → floor plan → shopping list → layout, i.e. each new screen-record beat is a bigger flex than the last.

## Reusable asset components
- **Selfie face-cam frame**: full-bleed vertical handheld selfie, arm-length framing, used for hook + close (bookend)
- **Location b-roll pan**: blurry handheld walk-and-reveal of physical space, establishes "before" state
- **Screen-record chat UI insert**: laptop-on-desk over-the-shoulder/top angle capturing a light-themed chat app scrolling, used repeatedly as the "proof" unit
- **Nested reference clip**: a borrowed/inset talking-head clip playing inside the chat UI as a cited reference — recursive proof device
- **AI-generated payoff render**: single striking full-screen generated image held ~4s as the emotional peak
- **Diagram/plan insert**: technical-looking floor-plan/blueprint screenshot signaling "depth" and specificity
- **Caption pill**: magenta rounded-rect + white bold text, the only recurring color-branded UI chrome

## Colors → content mapping notes
- Real world (office, host, laptop): natural desaturated grays/whites/wood tones, unbranded
- Screen-record UI: soft lavender/pink chat interface (ChatGPT's own light theme) — this is incidental to the app, not the creator's branding
- Only true "brand" color is the magenta/pink caption pill — a single consistent accent thread tying disparate footage together
- No consistent color-coding of content types otherwise; palette is largely dictated by whatever's literally in frame

## Weaknesses / what NOT to copy
- Heavy handheld blur/shake during location pans (frames 2-8, 48-49) — several seconds are genuinely blurry/unreadable, pure wasted visual real estate
- Screen-record segments are static over-the-shoulder shots with little camera movement — could easily feel monotonous without the caption pacing carrying it
- Nested reference-clip cutaways are muddy/low legibility (small inset on a laptop screen, hard to make out) — proof-of-credibility beat is visually weak
- No explicit CTA card or subscribe prompt at the end — ends abruptly on brand-name mention, no engagement ask
- Relies entirely on narration to justify screen content; a muted viewer would lose most of the mid-section meaning
