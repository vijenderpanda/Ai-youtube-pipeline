## Archetype
Talking-head explainer with heavy kinetic-stat overlays ("face-cam + data-viz b-roll").

## Hook mechanic (first 3s)
Absurd literal-metaphor visual (host standing on a tiny floating grass island in open water) paired with an oversized shock number ("2400L WATER") that pops in with a glow/scale animation. No verbal setup shown as text — the number itself is the hook, the island is a visual pun for "AI is draining a resource."

## Caption grammar
Two distinct caption registers:
1. **Stat numbers** — huge, bold, center-frame, glowing/embossed digits with a one-word unit label underneath (e.g. "2400L / WATER"), used over b-roll.
2. **Phrase captions** — small colored pill/badge, bottom-left near host's chin, 2-4 words, used during talking-head segments (e.g. "But Remember", "It's About The Data Center"). Pills act like chapter markers/subtitles rather than full transcript captions.
No word-by-word karaoke captions — this is a "sparse label" style, not dense caption-everything.

## Information density
Medium-high: a new stat or labeled graphic roughly every 1-3 seconds during data segments, but talking-head segments breathe for 3-5s uncaptioned while host explains verbally. Density oscillates: dense b-roll/stat blocks alternate with calmer host-explains blocks, giving a build-release rhythm.

## Reusable asset components
- **Liquid-fill container graphic** — glass/cylinder/bottle that fills proportionally to represent a stat (used for model sizes, everyday comparisons).
- **Stacked-glass pyramid** — rows of identical icons (water glasses) representing a large aggregate count.
- **App-window/UI screenshot mock** — a faux ChatGPT interface card used as "proof" mid-explainer.
- **US map heat/pin overlay** — country or state map that lights up with dots/pins tied to a stat, zooming from national to state level.
- **Area-comparison card** — simple colored square/circle labeled with a sq-mile or ratio number, for making abstract volumes tangible.
- **Factory/datacenter icon** — small line-icon graphic used as a location/industry marker.
- **Platform-funnel CTA graphic** — YouTube/Instagram/TikTok icons converging into a shared vessel — reuses the episode's core visual motif (water) for the subscribe ask instead of a generic subscribe card.
- **Line/bar chart build-up** — animated chart with sequential step captions, used twice (mid-video data proof, end-video closing "methodology" chart).

## Colors → content mapping notes
- Light powder-blue background (#d7e6f2-ish) = neutral "explainer" canvas, used for all graphic/chart beats.
- Saturated AI-blue (#1c6fd6-ish) = the accent for every stat number, container fill, and icon — consistently "this color = the AI/water cost" throughout, never used for anything else.
- Host wears a bright red-orange jacket — deliberately clashes with the blue palette so the host always pops out of blue graphics/backgrounds.
- Dark navy/black = reserved for realistic b-roll (server corridors, datacenter aerials, closing chart) — signals "real world footage / hard data" vs. the flat blue graphic layer signaling "illustrated stat."

## Weaknesses / what NOT to copy
- Several near-duplicate consecutive frames (host static for 1-2s) pad runtime without new info — trim harder.
- Some stat cards (e.g. "$3000 AI IMAGES" vs "$3000") show inconsistent formatting/units between adjacent beats — pick one consistent stat-card template.
- Runtime is 2:06, long for a Short — pacing relies on a strong host+niche topic to sustain, risky for a colder or less charismatic host.
- A couple of graphic beats (plain progress bars, blank blue cards) are visually weak filler with little info payload — cut or replace with a stat.
