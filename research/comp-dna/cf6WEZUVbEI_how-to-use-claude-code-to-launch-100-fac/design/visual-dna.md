# Visual DNA — cf6WEZUVbEI (Greg Isenberg, "How to use Claude Code to launch 100+ Facebook ads")

## Archetype
"Talking-head narrator + kinetic-graphic case-study reel" — host bookends and periodically re-anchors a mostly-graphic sequence of mockup ad cards, flowchart icons, and dashboard stats. Not a screen-record; all UI/product shots are designed mockups, not real captured screens.

## Hook mechanic (first 3s)
Cold open on a fake "old CRT monitor" showing glowing orange "CLAUDE CODE" boot text inside a webcam-in-media-player frame (mimics an old desktop recording). The retro-tech aesthetic + immediate brand-name callout in a novel visual (not a normal talking head) is the pattern interrupt. Countdown timers (14:00, 28:00) appear seconds later to imply real-time speed.

## Caption grammar
No burned-in word-by-word spoken captions in the sampled frames. Text on screen is entirely graphic/kinetic typography tied to beats: short lowercase italic connective phrases ("first,", "...and then simply / to simply / polish / the end / product.") delivered word-by-word/line-by-line as kinetic build, plus card-native labels (stat numbers, objection phrases, callouts like "High CTR"). Two distinct type registers: (1) serif italic for narrative connective tissue, (2) bold sans/mono for data/UI card content.

## Information density
Very high — a new visual concept roughly every 1-2s (cards, icons, mockups) intercut with host holds. Dense but organized via consistent motifs (robot mascot, teal color, card/pill shapes) so it doesn't feel chaotic. Host segments are the "breathing room" beats.

## Reusable asset components
- **Retro CRT boot card** — dark screen, monospace glow text, thick bezel frame (intro/brand-reveal device)
- **Ad mockup card** — square/portrait product ad with headline + subhead + small badge (e.g. "20% OFF"), swappable per-brand
- **Brief/input text card** — small serif label:value list (Brand/Product/Audience/Pain point/Benefit/Offer) inside a rounded card, used to show "the prompt/input"
- **Pill toggle/settings bar** — rounded horizontal bar with gear icons, denotes "config" step
- **Objection pill list** — stacked black rounded-rect labels with short pain-point phrases, fed by a flowchart
- **Icon-branch flowchart** — two source icons (video/comment) converging/branching via curved connector lines to outputs
- **Robot mascot icon** — small circular teal robot head, recurring "AI agent" avatar, appears at multiple scales
- **Social-post mockup** — ad image + like/comment/share icon row + fake comment thread, for "proof it performs" beats
- **Stat/dashboard card set** — 2x2 grid of black rounded stat tiles (label + big number) + line chart + mini ad gallery strip
- **Platform badge chip** — icon (Facebook "f") + label ("API") inside a small rounded tile, with a numeric counter badge
- **Vertical smear/funnel transition shape** — teal gradient hourglass/blur used as a wipe between sections
- **Kinetic type card** — cream bg, single word or short line, mixed serif-italic/bold weights, builds progressively

## Colors → content mapping notes
- Cream/warm-beige (#EDE7DE-ish) = default graphic-card canvas background throughout, keeps a premium/notebook feel distinct from typical black-bg tutorial shorts
- Deep teal/forest green (#1F5C4F) = the brand/system accent — used for icons, connector lines, pill fills, transition shapes; consistent "this is the AI/tool" signal color
- Lighter teal (#5FBDA8) = secondary accent for mascot, highlight badges
- Near-black (#111) = host background shadows, stat-card fills, retro-CRT bezel — a grounding neutral
- Orange (CRT glow only) = nostalgia/terminal callback, used exactly once at the hook, not repeated — a deliberate one-off accent, not part of the main palette

## Weaknesses / what NOT to copy
- No burned-in spoken captions sampled — risky for silent/mobile viewers; a cloned version should add readable captions
- Extremely dense cutting (near 1 new visual/sec) requires high production value (many custom mockups); hard to replicate cheaply without a real asset library
- Host segments are short and generic (no strong facial expression/gesture variety visible) — the graphics are doing the retention work, not the host performance
- Countdown-timer device (14:00/28:00) appears then is dropped — an unresolved narrative thread, don't reuse without paying it off
- All "product" screenshots are fabricated mockups, not real tool UI — if cloning for a tools-demo channel where authenticity matters, this approach risks feeling staged/unverifiable
