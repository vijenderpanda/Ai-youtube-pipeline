## Archetype
Talking-head opinion/explainer with data-chart + screenshot cutaways ("talking-head + evidence B-roll," no PIP host during B-roll — host goes fully off-screen, replaced by full-bleed proof).

## Hook mechanic (first 3s)
Opens NOT on the face but on a small line/leaderboard chart (release timeline), immediately paired with a direct question caption ("What do you think"). Within 2s cuts to host full-frame with the claim starting ("the biggest / moment / open source AI."). Hook is chart-first (credibility) then claim (stakes), not face-first.

## Caption grammar
One bold lowercase word or short phrase (1-4 words) burned in per ~1s beat, centered ~55-65% down the frame near the chin. Yellow fill, no stroke/heavy outline needed against the plain gray wall (implied thin dark stroke for contrast). Phrases chain into full sentences read across consecutive beats ("the biggest" → "moment" → "open source AI."). No emoji, no highlight-box, no karaoke-per-syllable — just word-at-a-time reveal.

## Information density
High for a 71s short: ~70 distinct caption beats, ~10 full-bleed B-roll/screenshot swaps, 4 distinct chart/gauge PIP types (leaderboard bar chart, market heatmap, speed gauge dial, token-throughput dot grid). Roughly one new visual idea every 3-5s — dense but each swap is legible at a glance (single stat or single screenshot, not busy composites).

## Reusable asset components
- **Circular avatar+chart insert** — small round PIP top-center over host showing a leaderboard bar chart or gauge dial when a stat is mentioned
- **Speed/throughput gauge dial** — radial dial visualization for a rate metric (tokens/sec)
- **Token-cost dot grid** — grid of colored dots + floating price tag to visualize scale/cost
- **Brand-logo chip pair** — two square icon chips side by side (e.g. OpenAI + Anthropic) to name-check companies instantly
- **Full-bleed hardware photo insert** — real product/rig photography replacing host frame entirely for cost/proof beats
- **Full-bleed terminal/code screenshot** — raw CLI output as "technical proof" cutaway
- **Full-bleed file-listing/download-page screenshot** — HuggingFace-style repo file browser to invite viewer self-verification
- **Line/timeline chart full-bleed opener** — release-timeline chart as the cold open before the host appears

## Colors → content mapping notes
- Yellow (#F5E642-ish) = all caption text, consistent brand color regardless of topic
- Red/dark heatmap = negative market movement (DeepSeek stock-crash analogy beat)
- Blue circular whale icon = DeepSeek brand reference
- White/orange/dark chip icons = OpenAI, Anthropic, Fable brand marks used as instantly-recognizable stand-ins for company names
- Plain neutral gray studio wall = default "no B-roll" state, keeps attention on host body language

## Weaknesses / what NOT to copy
- Zero hard cuts within the talking-head segments — pacing relies entirely on caption word-changes and B-roll swaps; if ported to a shorter/faster format this could feel static without those overlays doing the work
- Host performs in a plain gray room with visible power-strip/cable clutter and a bare wall — fine for authenticity/authority niche but reads as low-production if copied into a polished brand
- Some B-roll (hardware photos, terminal screenshots) are static stills held 1-2s with no motion/Ken-Burns — low visual interest on their own, only works because caption text carries them
- Ending punchline ("ban math") is untranslated/culturally-specific wit — don't copy verbatim, copy the *mechanic* (quotable one-liner mic-drop close) not the line itself
- No explicit CTA card/pill at the end — relies purely on the philosophical closer for retention/shares, weaker for driving subscribes if that's a goal
