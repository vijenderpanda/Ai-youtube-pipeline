## Why this template (the distribution case)

Built to score on every metric the feed's audition measures, using what our own data taught us:

| Audition signal | How this template plays it |
|---|---|
| Swipe-away (first ~2s) | Cold-open on the #1 item's most jaw-dropping PROOF slide + spoken claim. No intro, no branding first. |
| Watch-through | Ranked countdown 5→1 = built-in open loop ("what's #1?"). Payoff lands ~3s before the end. Our retention monsters are already curriculum; the rail adds pull. |
| Mid-video bleed (our known 5–13s dead zone) | Hard pattern-interrupt every 2–3s: WHITE minimal card ↔ DARK proof slide alternation. The eye never settles. |
| Loops (rewatches count) | FINAL frame is visually identical to frame 0 — the Short loops seamlessly, so a rewatch feels intentional, not restarted. |
| Reactions/subs (our weakest layer: 0.34/100) | Sol appears ONLY in the last ~3s as a human pattern-interrupt with the SPOKEN series-CTA + specific next-episode tease. |
| Tail (search re-auditions forever) | Title = search-intent list grammar ("Top 5 Claude Code ___ that ___"). Items must be EVERGREEN tools/commands — never news. Pinned comment lists all 5 (SEO + engagement). |

## Beat grammar (30s ± 4)

1. **HOOK · 0–2.0s** — #1's proof slide (real screenshot, one highlight pill with a concrete
   number) + spoken claim ("Five Claude Code plugins. Number one feels illegal.").
2. **ITEMS 5→2 · ~5s each** — every item is a two-slide pair:
   - **Card slide (white):** huge kinetic serif ordinal ("THE FIFTH") + tool icon-card + name.
     Playfair Display — already our locked display face (Vaibhav-DNA render system).
   - **Proof slide (dark):** real screenshot, ONE highlight pill with ONE number
     ("251 providers — 90+ free" energy). Top-strip caption ≤7 words carries the VO.
3. **PAYOFF #1 · ~6s** — biggest beat: card + two proof slides. The rank-1 reveal is the climax.
4. **END · last 2.5–3s** — Sol full-frame (the ONLY host moment): spoken
   "Tomorrow: [specific next-ep tease] — follow so it finds you." over the outro card.
   Last 0.5s cuts back to the HOOK frame → seamless loop.

## Locked craft params (inherited)

- Runtime 30s ±4 · vertical 9:16 · bed -14 LUFS · VO style 0.4, 0.4s sentence gaps
- Captions: top strip, ≤7 words/line, baked (poly baked-text flow, no overlay cards)
- Kinetic type: Playfair Display, gradient ink allowed on ordinals; body stays system sans
- Demos: REAL screenshots only, annotated with highlight pills; never mockups of fake numbers
- Step chips / pills sit in dead space, never on taught content (VJ rule)

## Packaging (the tail design)

- **Title:** search-intent list grammar — "Top 5 Claude Code ___ That ___" (+ 1 emoji max).
- **Description line 1:** Vaibhav-DNA hook grammar (the emotional line the title doesn't carry).
- **Description line 2:** the series promise ("One 30-second Claude trick, every day.") + "Ranked #N".
- **Pinned comment:** the full ranked list, one line each — SEO surface + saves viewers a rewatch
  scrub (paradoxically increases full rewatches).

built for daily-cadence economics.
