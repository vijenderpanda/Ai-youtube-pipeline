## ⚠️ Accuracy gates (brand = anti-hype; verify LIVE at production)
- "Free" here = **free tiers with daily-refreshing credits** (Seedance 100/day, Kling 66/day, Hailuo 3–5/day) or **open weights you self-host** (Chatterbox, Flux, Wan) — i.e. *"free indefinitely, but capped per day / needs setup."* Voice the cap + the setup cost honestly; don't imply unlimited-instant.
- **Chatterbox "beats ElevenLabs"** is per blind-test reports — attribute it ("in blind tests"), don't state as absolute.
- **The orchestration** (Seg 4) may use **Claude Code**, which needs a Claude paid plan — that's *the one thing you pay for*, which is on-thesis; state it plainly, don't pretend the brain is free too.
- **Seg 4 (AI presenter):** HeyGem/Duix is **self-hosted** (needs a GPU — our RTX 3060 worker; offline). Free commercial use to **100k users / $10M rev** (Duix license) — state the self-host cost honestly, don't imply cloud-instant. Best proof = show it animating **our own Sol** for free.
- In-house mocks / no logos for the wrapper graphic + anything not filmable (§13). "Not affiliated with…" lists **every** named tool + lab (Anthropic, Alibaba, ByteDance, Kuaishou, Tencent, MiniMax, Silicon Intelligence, ElevenLabs, Leonardo, Canva, Higgsfield, HeyGen).
- Model names/versions move fast — re-verify each tool's free tier + current version at production (`record_demo.py --preflight` where filmable).
