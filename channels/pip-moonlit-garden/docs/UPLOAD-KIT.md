# Upload Kit & SEO — Lulla's Moonlit Garden

Everything to publish correctly and rank. Kids SEO optimizes for **watch-time loops, thumbnails, and playlists** — not clever titles.

---

## A. Channel setup (one-time)
1. **Name/handle:** verify `@lulla` / `@lullasmoonlitgarden` / `@moonlitgarden` availability (see Brand Bible §10). Lock the same handle on TikTok + Instagram.
2. **Channel art:** banner = Lulla + wordmark + "Calm bedtime songs for little ones" (Fredoka font). Profile pic = Lulla's face on indigo.
3. **About:** "Gentle, calming bedtime songs and lullabies for babies and toddlers 🌙 New soothing songs every week. Dim the lights, snuggle in, and drift off with Lulla in the Moonlit Garden."
4. **⚠️ Audience default:** Settings → Channel → Advanced → set **"Yes, set this channel as made for kids"** (or set per-video — see C). This is a legal (COPPA) requirement.
5. Create playlists: **"🌙 Bedtime Songs"**, **"😴 Sleep Music (30–60 min)"**, **"🎵 All Lulla Songs"**.

## C. Made-for-Kids compliance checklist (every upload)
- [ ] Mark video **"Made for kids"** (required).
- [ ] Understand the trade-off: no personalized ads, **no comments**, no cards/notifications/end-screen-subscribe, no channel memberships on MFK videos. (This is COPPA — unavoidable.)
- [ ] No data-collection widgets. Keep it clean.
- [ ] Audio safe: consistent soft volume, no sudden loud stings (toddler-safe).
- [ ] Original song + original character (avoid the July-2025 "inauthentic/mass-produced" flag).

---

## D. Upload settings
- **Resolution:** export 1080p now (4K later — kids content is heavily watched on TVs; 4K helps).
- **Category:** *Music* (or *Education*).
- **Thumbnail:** 1280×720.
- **Playlist:** add to "🌙 Bedtime Songs" + "🎵 All Lulla Songs".
- **Schedule:** publish on a **fixed day/time** (e.g., Fri 6pm local) — consistency trains the algorithm and parents.
- **Language/captions:** set video language English; add captions (helps SEO + accessibility).

---

## E. Growth loop (the money mechanics)
1. **Cadence:** 2–3 singles/week + 1 compilation/week, same schedule.
2. **Compilations (30–60 min):** the watch-time/RPM driver — bundle 8–15 songs back-to-back.
3. **Playlists:** chain songs so autoplay never stops = the growth engine.
4. **24/7 sleep live stream:** once you have ~10 tracks (top revenue format for kids).
5. **Multi-language:** dub winners (Synthesia/Kapwing) → "Lulla — Español / हिंदी / …" = up to 5× the view pool at ~zero extra cost. **Biggest lever to reach $200/mo.**
